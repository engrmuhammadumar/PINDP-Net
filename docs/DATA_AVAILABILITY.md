# Data Availability

This study uses the PHM 2010 milling benchmark. The raw sensor and wear files
are third-party data and remain subject to the original provider's access and
redistribution conditions; consequently, the authors do not redistribute the
raw dataset. The dataset can be obtained from the official source cited in the
manuscript. After authorized download, this repository supplies a directory
template, integrity-checking script, and filename, size, and SHA-256 manifest.
Reference-dependent evaluation uses C1, C4, and C6. C2, C3, and C5 are treated
solely as blind-inference trajectories.
