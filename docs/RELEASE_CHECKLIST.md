# Public-release checklist

- [ ] Genuine feature extraction, preprocessing, model, training, inference,
      uncertainty, evaluation, and plotting code is present.
- [ ] Complete configurations, seeds, and outer and inner splits are present.
- [ ] OOF predictions for C1, C4, and C6 pass validation.
- [ ] Blind files contain only C2, C3, and C5 and no reference labels.
- [ ] Baseline outputs are direct saved predictions, not reconstructed curves.
- [ ] Prediction files reproduce every manuscript metric and curve.
- [ ] Residual, stage, and pooled metrics use the same final OOF file.
- [ ] Model-only and end-to-end latency are clearly distinguished.
- [ ] Raw data, absolute paths, credentials, and hidden labels are absent.
- [ ] A license is approved by all relevant rights holders.
- [ ] Citation metadata contains every author correctly.
- [ ] Repository and archive links work while signed out.
- [ ] The one-command verification completes successfully.
